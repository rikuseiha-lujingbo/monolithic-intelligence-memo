# 下一代单体智能：架构可行性探讨

一份关于"下一代单体智能（Monolithic Intelligence）"的技术备忘录，系统梳理其架构可行性、关键科学障碍，以及 2025–2026 年的工程突破。

> 一句话概括核心论断：**壳能造、魂未至，但魂的雏形已现。**

---

## 这篇文档讨论什么

从"人脑每次思考时，上下文信息从哪里来"这一朴素问题出发，推演一个自包含、有边界、能持续存在的智能体所必需的架构要素。全文围绕一条主线展开：

- **外壳已可拼出**：有状态单实例、内化记忆、内部检索，在现有工程（MemGPT、Zep、TTT 等）上已有可用原型。
- **灵魂仍在前沿**：持续可写记忆、自我巩固、像生物一样会遗忘而不灾难性遗忘，仍是开放问题。
- **突破口在 TTT**：2025 年 SSM、记忆网络、可塑权重三条线汇流于 Test-Time Training——模型在运行时通过梯度 / Hebbian 规则更新内部状态。

## 关键概念索引

- **可写状态 / 内化记忆**：TTT、Titans、Mamba、MesaNet、Gated DeltaNet
- **互补学习系统（CLS）**：海马式暂存层 + 新皮层式稳固层 + 离线睡眠巩固
- **冲突裁决**：scope 并存 / 再巩固 / 软标记 / 升级人工 / 保留慢记忆五策略
- **硬件契约**：CPU 管状态记忆、FPGA 管每步可写、GPU 管离线巩固
- **世界模型与自体模型**：JEPA、V-JEPA 2、过去—未来—自我三维
